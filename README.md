# Hi, I'm Vamsi 👋

Second-year Computer Science student at **Manipal Institute of Technology**, working on embedded systems and flight software for **Team Parikshit**, the institute's student satellite team.

## What I work on

- **Flight software for a guided-parafoil CanSat** (IN-SPACe CAN-7USAT 2026-27, Team 017): embedded C/C++ firmware for the Arduino and Teensy flight computers
- **Ground control station**: a React/TypeScript dashboard with live telemetry over Web Serial, a 3D attitude view, offline maps, and a landing predictor
- **STM32 firmware**: sensor drivers (RM3100 magnetometer), flash-based EEPROM emulation, ADC and PWM peripherals
